# Security policy

## Supported versions

Only the latest published version of `@dean0x/tokenmeter` gets fixes.

## Report a problem

Do not open a public issue for a security problem.

1. Go to the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Give the version, your platform and the steps that show the problem.

You get an answer in 7 days or less.
A fix goes into a new version.
The release notes state the effect of the fix.
